# Content Generation Prompts for the client

## Purpose
This file contains reusable prompts for generating SEO-optimized content for the client (→ See client.md#domains). Use these prompts to maintain consistency and quality across all content types.

**Content Pillars:** SEO & Search Marketing, Digital Advertising, Web Analytics & Data, E-commerce Marketing, Digital Strategy
**Target Audiences:** Small Business Owners, Marketing Managers, E-commerce Directors, Startup Founders, Enterprise Teams
**Languages:** English ([your-domain.com]) + Russian ([your-domain.ru])

## 1. Service Guide Prompt

### Template Prompt
```
Write a comprehensive service guide for the client with the following specifications:

LANGUAGE: [English/Russian]
PRIMARY KEYWORD: [insert primary keyword]
SECONDARY KEYWORDS: [insert 3-5 secondary keywords]
TARGET WORD COUNT: 2,000-2,500 words
TARGET AUDIENCE: [specify - e.g., e-commerce managers looking to improve organic traffic]

ARTICLE STRUCTURE:
1. Title with primary keyword and audience/use case
2. Introduction (150-200 words) - The business challenge this audience faces
3. Why [audience] needs professional [service] support
4. How [YOUR-BRAND] approaches this (methodology overview, not sales pitch)
5. Step-by-step: What working with [YOUR-BRAND] looks like
   - Step 1: Initial audit and analysis
   - Step 2: Strategy development
   - Step 3: Implementation
   - Step 4: Monitoring and optimization
   - Step 5: Reporting and iteration
6. Real-world example scenario with specific results
7. Results and benefits (what to expect after 1-3 months)
8. FAQ section (5-8 questions)
9. Conclusion with CTA

SEO REQUIREMENTS:
- Primary keyword in: title, first paragraph, one H2, conclusion
- Secondary keywords distributed naturally
- 3-5 internal links to [YOUR-BRAND] service pages and related blog posts
- 1-2 external links to authoritative sources (Google documentation, industry research)
- Meta title (50-60 characters)
- Meta description (150-160 characters)
- Article schema markup

TONE: Professional, helpful, authoritative but approachable
PERSPECTIVE: Knowledgeable peer, not salesperson

CTAs (choose appropriate):
- → See client.md#ctas for CTA options per language


Include:
- Specific, actionable examples relevant to the audience
- Image placeholders for key steps
- Service mentions integrated naturally (not forced)
- Comparison to doing it in-house or with generic tools
```

### Example Usage
```
LANGUAGE: English
PRIMARY KEYWORD: SEO for e-commerce
SECONDARY KEYWORDS: online store SEO, e-commerce search optimization, product page SEO, category page optimization
TARGET WORD COUNT: 2,200 words
TARGET AUDIENCE: E-commerce managers with 500+ SKU catalogs
```

## 2. Comparison Article Prompt

### Template Prompt
```
Write a detailed comparison article for the client with the following specifications:

LANGUAGE: [English/Russian]
COMPARISON TYPE: [Tool A vs Tool B / Best X Tools Listicle / Agency vs In-house]
PRIMARY KEYWORD: [comparison keyword]
SECONDARY KEYWORDS: [related comparison terms]
TARGET WORD COUNT: 1,800-2,200 words

ARTICLE STRUCTURE (for tool comparisons):
1. Title: "[Tool A] vs [Tool B]: [Key Differentiator] in [Year]"
2. Introduction - Why this comparison matters, who should read
3. Quick comparison table:
   | Feature | Tool A | Tool B |
   | Pricing | ... | ... |
   | Best For | ... | ... |
4. Tool A overview (200-250 words) - key strengths
5. Tool B overview (200-250 words) - key strengths
6. Head-to-head comparison by category:
   - Core functionality
   - Ease of use and learning curve
   - Reporting and analytics
   - Integrations
   - Pricing and value
   - Support and documentation
7. Who should choose which tool
8. FAQ section (5-8 questions)
9. Verdict and CTA

ARTICLE STRUCTURE (for "Best X Tools" listicle):
1. Title: "[Number] Best [Category] Tools in [Year]"
2. Introduction with selection criteria
3. Quick comparison table of all tools
4. Detailed review of each tool (150-200 words):
   - Key features, pricing, best for, limitations
5. How to choose the right tool
6. FAQ section
7. Conclusion

SEO REQUIREMENTS:
- Both tool names in title (for vs articles)
- Comparison schema markup where applicable
- Links to [YOUR-BRAND] service pages
- Fair, balanced comparison (builds trust)
- Include pricing information

TONE: Objective, analytical, fair — acknowledge each tool's strengths honestly
LANGUAGE: [English/Russian]
GOAL: Help readers make an informed decision

Important:
- Be genuinely fair — biased comparisons hurt credibility
- Acknowledge where each option excels
- Focus on fit, not "winning" — different tools suit different needs
- Use real feature differences, not vague claims
- Mention how [YOUR-BRAND] helps clients choose and implement the right tools
```

### Example Usage
```
LANGUAGE: English
COMPARISON TYPE: Tool A vs Tool B
PRIMARY KEYWORD: Google Analytics 4 vs Yandex Metrica
SECONDARY KEYWORDS: GA4 alternative, web analytics comparison, analytics tool comparison
TARGET WORD COUNT: 2,000 words
```

## 3. How-To Tutorial Prompt

### Template Prompt
```
Write a step-by-step how-to tutorial for the client:

LANGUAGE: [English/Russian]
PRIMARY KEYWORD: [insert primary keyword]
SECONDARY KEYWORDS: [insert 3-5 secondary keywords]
TARGET WORD COUNT: 1,500-2,000 words
TARGET AUDIENCE: [specify experience level and role]

ARTICLE STRUCTURE:
1. Title: "How to [Action]: [Benefit or Complete Guide]"
   - RU: "Как [действие]: [польза или полный гайд]"
2. Introduction - What reader will learn, why it matters
3. Prerequisites
   - What you need before starting
   - Estimated time to complete
   - Difficulty level (beginner/intermediate/advanced)
4. Step-by-step instructions (5-10 steps)
   - Each step with clear H3 heading
   - Detailed explanation with context
   - Screenshot/image placeholder
   - Pro tip for each step
   - Common mistake to avoid
5. Tips for success (bullet list of 5-7 tips)
6. Common problems and solutions
7. FAQ section (5-8 questions)
8. Conclusion with encouragement and CTA

SEO REQUIREMENTS:
- Primary keyword in: title, introduction, conclusion
- HowTo schema markup structure (required)
- Include step numbers in headings (Step 1 / Шаг 1)
- 3-5 internal links to related tutorials and service pages
- 1-2 external authoritative sources
- Meta title and description optimized

TONE: Instructional, friendly, encouraging
FORMAT: Clear, scannable with short paragraphs

Include:
- Specific, actionable steps
- Expected results at each stage
- Time estimates per step
- Difficulty level indicator
```

### Example Usage
```
LANGUAGE: English
PRIMARY KEYWORD: how to set up Google Analytics 4
SECONDARY KEYWORDS: GA4 setup guide, install GA4, configure GA4 for e-commerce, GA4 event tracking
TARGET WORD COUNT: 1,800 words
TARGET AUDIENCE: Marketing managers setting up analytics for the first time

## 7. FAQ Content Prompt

### Template Prompt
```
Create comprehensive FAQ content for the client:

LANGUAGE: [English/Russian]
TOPIC: [SEO / PPC advertising / analytics / web development / e-commerce / pricing / services]
PRIMARY KEYWORD: [insert relevant keyword]
NUMBER OF QUESTIONS: 8-12
TARGET AUDIENCE: [specify]

STRUCTURE:
1. FAQ page title
2. Brief introduction (50-100 words)
3. Questions organized by theme
4. Each answer: 100-200 words with detailed, helpful information

QUESTION TYPES TO INCLUDE:
- Service questions (What does SEO include? How long until I see results?)
- Process questions (How do you start? What does a typical engagement look like?)
- Pricing questions (How much does SEO cost? What's included in each plan?)
- Technical questions (Do you work with my CMS? What tools do you use?)
- Results questions (What ROI can I expect? How do you measure success?)
- Industry questions (Is SEO worth it for [industry]? How does PPC compare to SEO?)

SEO REQUIREMENTS:
- FAQPage schema markup for all Q&As (required)
- Questions should include long-tail keywords naturally
- Link to relevant service pages and guides in answers
- Each question as H3 heading
- Answers should target featured snippets (clear, direct first sentence)

TONE: Helpful, patient, comprehensive
FORMAT: Scannable, easy to read, direct answers first

Ensure answers:
- Start with a direct answer (first sentence answers the question)
- Then provide context and details
- Include links to deeper resources where relevant
- Build trust with specific, honest information
- Include CTAs where appropriate (→ See client.md#ctas)
```

## 8. Meta Tag Prompts

```

- [ ] Valuable, original information

- [ ] No grammar or spelling errors

- [ ] Actionable and specific
- [ ] Meets minimum word count (1,800 words)

BILINGUAL CHECKS (if applicable):
- [ ] Proper language quality (not machine-translated)
- [ ] Cultural appropriateness for target market

## Notes for Using These Prompts

### Best Practices:
1. Always customize the prompt with specific details before using
2. Review and edit AI-generated content for accuracy and language quality
3. Run content through the `/review-article` critic system before publishing
4. Save generated content in `/content/drafts/` first
5. Ensure bilingual consistency — if publishing EN article, plan RU equivalent

### Required Information Before Using Prompts:
- Target keyword (from `research/keywords/priority-keywords.md`)
- Target audience (business owners, marketing managers, e-commerce directors, etc.)
- Specific client services to mention (if applicable)
- Word count target
- Publication timeline
- Language (EN/RU/both)

### After Content Generation:
1. Review language quality (native-level, not translated)
2. Fact-check all claims and data
3. Run `/review-article` for multi-critic assessment
4. Generate AI images for visual content
5. Add schema markup
6. Build internal links (check content calendar for link targets)
7. Prepare hreflang equivalent if publishing for both sites
