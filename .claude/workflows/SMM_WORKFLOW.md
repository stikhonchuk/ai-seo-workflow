# SMM Content Workflow

This workflow guides the process of creating social media content from blog articles (repurposing) or creating original social posts.

→ See `client.md#social-media-channels` for channel list, tones, posting times, and rules.
→ See `client.md#utm-convention` for UTM parameter format.

**Triggered by:** Phase 7 in SEO Master Workflow (after article is published)
**Skill:** `/create-social-posts` (Sonnet)
**Strategy Reference:** [research/smm-strategy.md](../../research/smm-strategy.md)

---

## Workflow Overview

```
Blog Article Published
    ↓
Step 1: Extract Key Points (3-7 insights per article)
    ↓
Step 2: Adapt for Each Channel (tone, format, length)
    ↓
Step 3: Create Visual Assets (if needed)
    ↓
Step 4: Schedule Across 7-Day Window
    ↓
Step 5: Track Performance
```

---

## Step 1: Extract Key Points from Source Content

For each blog article, extract:

- **Main thesis** (1 sentence — becomes LinkedIn/X hook)
- **3-7 key insights** (each becomes a standalone social post)
- **1 counterintuitive/surprising fact** (becomes engagement post)
- **1 actionable tip** (becomes Instagram Reel / VK Clip)
- **1 discussion question** (becomes LinkedIn poll / Telegram poll)
- **1 data point or statistic** (becomes shareable graphic)
- **1 template or checklist** (becomes Telegram downloadable)

## Step 2: Channel-Specific Adaptation

### LinkedIn (EN — Team/Enterprise)

**Tone:** Professional, data-driven, insight-led. First-person from founder/expert.

**Format Options:**
| Format | When to Use | Length |
|--------|-------------|--------|
| Text post + image | Key insight, opinion | 150-300 words |
| Carousel (multi-image PDF) | Step-by-step, listicle | 5-10 slides |
| Document post | Methodology guide, checklist | 3-7 pages |
| Poll | Research question, audience engagement | 2-4 options |
| Short video | Product demo, expert tip | 30-90 seconds |

**Structure (text posts):**
```
Hook line (question or bold statement)

[blank line]

3-5 paragraphs of insight
- Use line breaks for scannability
- Include data or specific example
- End with takeaway

[blank line]

CTA: question, link, or "follow for more"

#SEO #DigitalMarketing #MarketingStrategy [2-3 relevant hashtags]
```

**Rules:**
- NO external links in post body (algorithm penalty) — put link in first comment
- 4 educational posts : 1 soft promotion : 1 hard CTA (4-1-1 rule)
- Tag relevant people/companies when mentioning them
- Respond to ALL comments within 24 hours

### Telegram (RU — B2B + Community)

**Tone:** Expert, in-depth, community-focused. Informal but authoritative.

**Format Options:**
| Format | When to Use | Length |
|--------|-------------|--------|
| Long-form post | Deep analysis, methodology | 500-1500 words |
| Quick tip | Daily actionable insight | 50-150 words |
| Poll | Audience research, engagement | 2-4 options |
| File attachment | Template, checklist, PDF | — |
| Forward + commentary | Curated industry content | 50-100 words |

**Structure (long-form):**
```
📌 [Bold headline]

[2-3 sentence intro — problem statement]

[Main content — can be long, Telegram supports it]
• Use bullet points
• Include examples
• Reference [YOUR-BRAND] naturally (not forced)

💡 Вывод: [Key takeaway]

🔗 [Link to blog article or product]

#SEO #ДиджиталМаркетинг #ИнтернетМаркетинг
```

**Rules:**
- Post when RU audience is online: 10-12 AM or 7-9 PM Moscow time
- Use Russian natively — NOT translated from English
- Include downloadable resources (PDFs, spreadsheets) — high engagement
- Cross-promote: mention Telegram channel in blog articles

### Instagram (EN — Personal/Family)

**Tone:** Inspirational, visual, action-oriented. Friendly and motivating.

**Format Options:**
| Format | When to Use | Priority |
|--------|-------------|----------|
| Reel (60 sec) | Tips, transformations, challenges | **Primary** |
| Carousel (5-7 slides) | Step-by-step guides, listicles | Secondary |
| Story | Quick polls, behind-scenes, daily tips | Daily |
| Static post | Quotes, milestones, announcements | Occasional |

**Reel Structure:**
```
0-3 sec: Hook (text overlay: "Your SEO strategy is missing this")
3-15 sec: Problem statement
15-45 sec: Solution / tips (numbered)
45-55 sec: Result / transformation
55-60 sec: CTA ("Follow for more" or "Link in bio")

Caption:
[Expand on the tip — 100-200 words]
.
.
.
[Hashtags: 5-10 relevant, mix of broad + niche]
#DigitalMarketing #SEOTips #[YourBrand] #MarketingStrategy #Analytics
```

**Carousel Structure:**
```
Slide 1: Bold headline (hook)
Slides 2-6: One point per slide (large text, clean design)
Slide 7: Summary + CTA ("Save this for later" or "Get a free consultation")
```

**Rules:**
- Reels = primary content type (50% of IG time, best discovery)
- Use trending audio where it fits naturally
- Post optimal times: 9-11 AM or 7-9 PM local time of target audience
- Stories daily for algorithm favor (polls, questions, behind-scenes)
- CTA: "Link in bio" (not external links — IG doesn't support them in posts)

---

### X/Twitter (EN — B2B Secondary)

**Tone:** Concise, punchy, conversation-starting. Expert but accessible.

**Format Options:**
| Format | When to Use | Length |
|--------|-------------|--------|
| Thread (7-10 tweets) | Blog article repurpose | 7-10 posts |
| Single tweet | Quick tip, hot take | 1-2 sentences |
| Poll | Engagement, research | 2-4 options |
| Quote tweet | Industry commentary | 1-2 sentences |
| Short video | Product demo, tip | 30-60 sec |

**Thread Structure:**
```
Tweet 1: 🧵 Hook: "I've managed 100+ SEO campaigns for businesses. Here's what most get wrong:"
Tweet 2-8: One point per tweet, numbered
Tweet 9: Summary / conclusion
Tweet 10: CTA + link to full article

Like + RT if helpful 🔄
```

**Rules:**
- Short video has 6x engagement advantage on X — prioritize
- Don't spend more than 15-20% of social effort here
- Engage with digital marketing/SEO community (reply, quote-tweet)
- Use 1-2 hashtags max (X algorithm doesn't favor heavy hashtag use)

---

### VKontakte (RU — Personal/Family)

**Tone:** Friendly, accessible, community-oriented. Less formal than Telegram.

**Format Options:**
| Format | When to Use | Priority |
|--------|-------------|----------|
| VK Clip (short video) | Tips, challenges | Primary |
| Community post + image | Tips, discussions | Secondary |
| Article | Long-form (adapted from Telegram) | Occasional |
| Poll | Engagement | Weekly |

**Rules:**
- Adapt from Telegram content — NOT identical copy
- VK Clips = adapted Instagram Reels with Russian voiceover/text
- Community (group) format — build community around digital marketing
- Cross-post is OK but change format and opening
- 2-3 posts/week (secondary channel)

## Step 4: Publishing Schedule

### 7-Day Repurposing Window (Per Blog Article)

| Day | Action | Channel |
|-----|--------|---------|
| Day 1 (Publish day) | Blog goes live + LinkedIn text post | LinkedIn |
| Day 1 | Long-form post (RU adapted) | Telegram |
| Day 2 | Thread (7-10 tweets) | X/Twitter |
| Day 2 | Carousel (5-7 slides) | Instagram |
| Day 3 | Reel (60 sec tip) | Instagram |
| Day 4 | Poll or discussion question | LinkedIn |
| Day 4 | Adapted post with infographic | VKontakte |
| Day 5 | Story (quick tip extract) | Instagram |
| Day 7 | Thought leadership angle | LinkedIn |
| Day 7 | Downloadable template/checklist | Telegram |

### Weekly Cadence (2 blog articles/week = Mon EN + Thu RU)

| Day | EN Channels | RU Channels |
|-----|-------------|-------------|
| Mon | LinkedIn (blog Day 1) | Telegram (RU blog Day 1) |
| Tue | X Thread + IG Carousel | — |
| Wed | LinkedIn (thought leadership) | Telegram (expert post) |
| Thu | IG Reel | Telegram (EN blog adapted to RU) + VK |
| Fri | LinkedIn (engagement) | Telegram (resource/template) |
| Sat/Sun | IG Story | VK Clip |

## Step 5: Performance Tracking

### Weekly Metrics Check

| Metric | LinkedIn | Telegram | Instagram | X | VK |
|--------|----------|----------|-----------|---|-----|
| Followers/Subscribers | count | count | count | count | count |
| Post impressions | avg/post | views/post | reach/post | impressions | reach |
| Engagement rate | % | reactions | % | % | % |
| Link clicks | count | count | bio clicks | count | count |
| Top performing post | note | note | note | note | note |

### Monthly Metrics

- **Consultation requests attributed to social** (UTM tracking)
- **Cost per lead by channel** (time investment if organic)
- **Best performing content type per channel**
- **Follower growth rate** (month-over-month)

### UTM Convention

```
?utm_source=[platform]&utm_medium=social&utm_campaign=[content-type]-[month]&utm_content=[post-id]

Examples:
?utm_source=linkedin&utm_medium=social&utm_campaign=seo-guide-mar26&utm_content=carousel-01
?utm_source=telegram&utm_medium=social&utm_campaign=analytics-setup-mar26&utm_content=expert-post
```

## Quality Checklist (Before Publishing)

### Every Post
- [ ] Adapted for platform (not cross-posted verbatim)
- [ ] Correct tone for channel
- [ ] CTA included (follow, link, save, share)
- [ ] Hashtags appropriate for platform
- [ ] UTM parameters on all links
- [ ] Image/video meets platform specs
- [ ] Scheduled at optimal time for audience timezone
- [ ] Russian content written natively (not translated)

### Monthly
- [ ] Content mix follows 4-1-1 rule (educational : soft promo : hard CTA)
- [ ] All 5 channels received content
- [ ] Community challenges promoted (if active)
- [ ] Performance metrics reviewed
- [ ] Top performers identified for boost/repurpose
- [ ] Underperformers analyzed — adjust strategy
