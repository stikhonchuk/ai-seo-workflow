# SEO Content Publication Plan for the client

## Publication Calendar Overview

This plan tracks SEO content strategy for the client (→ See client.md#domains). Content is published in both English and Russian, targeting SEO, digital advertising, web analytics, e-commerce marketing, and digital strategy topics.

**Data Sources:**
- Keywords: `research/keywords/priority-keywords.md`
- Competitors: `research/competitors/competitor-analysis.md`
- Content audit: `research/content-audit/`

## Monthly Content Goals

### Month 1 (Foundation)
- **Target:** 8 articles (4 EN + 4 RU)
- **Focus:** Highest-priority keywords, foundational how-to content
- **Content Mix:** 25% How-To Guides, 25% Case Studies, 25% Tool Reviews, 25% Strategy Guides

### Month 2 (Expansion)
- **Target:** 8 articles (4 EN + 4 RU)
- **Focus:** Comparison articles, industry analysis, more case studies
- **Content Mix:** 25% Comparisons, 25% Case Studies, 25% How-To, 25% Industry Analysis

### Month 3 (Authority)
- **Target:** 8 articles (4 EN + 4 RU)
- **Focus:** Pillar content, comprehensive guides, thought leadership
- **Content Mix:** 25% Pillar Content, 25% Case Studies, 25% Tool Reviews, 25% Templates

Use this template when planning each article:

**Language:** EN/RU
**Publish Date:** YYYY-MM-DD
**Status:** Not Started / Drafting / Review / Ready / Published

**Primary Keyword:** [keyword] ([volume]/mo, difficulty: [X])
**Secondary Keywords:** [kw1], [kw2], [kw3]
**Search Intent:** Informational / Commercial / Transactional
**Content Type:** How-To / Case Study / Comparison / Tool Review / Strategy Guide / Template

**Target URL:** /blog/[slug]
**Target Word Count:** 1,800-2,500

**Outline:**
1. Introduction — [hook/problem statement]
2. [H2 Section 1]
3. [H2 Section 2]
4. [H2 Section 3]
5. [H2 Section 4]
6. Conclusion — [summary + CTA]
7. FAQ (3-5 questions)

**Internal Links (planned):**
- /services/[relevant-service]
- /blog/[related-article] (when published)
- /cases (case studies page)

**CTA Strategy:**
- After value delivery: "Get Free Consultation" / → See client.md#ctas
- End of article: Contact form or consultation CTA

**Service Mentions:** [Which client services to naturally reference]

**Pre-Publishing Checklist:**
- [ ] Primary keyword in H1, first 100 words, meta title
- [ ] Meta title: 50-60 chars
- [ ] Meta description: 150-160 chars with CTA
- [ ] URL clean: /blog/[keyword-slug]
- [ ] Internal links: 3-5 per 1,000 words
- [ ] Hero image prompt created
- [ ] Run `/review-article` — score ≥ 7/10
- [ ] Schema markup ready (Article, FAQ)
