# Keyword Research Template for the client

1. Start with seed keywords organized by service category
2. Expand using keyword research tools (Google Keyword Planner, Yandex Wordstat)
3. Analyze each keyword using the priority matrix criteria
4. Map keywords to content types and target pages
5. Create content calendar from prioritized keywords

- Existing seed keywords: `research/keywords/seed-keywords.md`
- Priority keywords (top 50): `research/keywords/priority-keywords.md`

## Keyword Analysis Criteria

### Priority Matrix

**High Priority (Start Here):**
- Search volume: 500+ (EN) / 2,000+ (RU)
- Keyword difficulty: <40
- High business relevance: Direct match to [YOUR-BRAND] services
- Search intent: Transactional or Commercial
- Current ranking: Not ranking or position 11-50

**Medium Priority (Phase 2):**
- Search volume: 200-500 (EN) / 500-2,000 (RU)
- Keyword difficulty: 40-60
- Medium business relevance: Related to digital marketing
- Search intent: Commercial or Informational (high-value)
- Current ranking: Position 51-100

**Low Priority (Long-term):**
- Search volume: <200 (EN) / <500 (RU)
- Keyword difficulty: 60+
- Lower business relevance: Peripheral topics
- Search intent: Informational (awareness stage only)

### Evaluation Questions for Each Keyword
1. Does this keyword match what [YOUR-BRAND] offers?
2. Would someone searching this be interested in The client's services?
3. Can we create unique, valuable content for this keyword?
4. Is the keyword difficulty achievable for our domain authority?
5. Does the search volume justify content creation effort?
6. What is the user's intent? (Hire, Compare, Learn, or Problem-solving?)

## Keyword Research Tools & Process

### Free Tools (Start Here)
1. **Google Keyword Planner** — Search volume and competition data
2. **Google Search Console** — Current ranking data
3. **Google Trends** — Seasonal trends and regional interest
4. **AnswerThePublic** — Question-based keywords (3 free searches/day)
5. **Ubersuggest** — Limited free searches (3/day)
6. **Google Autocomplete** — Type seed keywords, note suggestions
7. **People Also Ask** — Scroll Google results for question keywords
8. **Related Searches** — Bottom of Google results page
9. **Keyword Surfer (Chrome Extension)** — Search volume in Google results
10. **Yandex Wordstat** — Russian market (free, requires Yandex account)

### Paid Tools (Optional)
1. **Ahrefs** — Comprehensive keyword research + competitor analysis ($99/mo)
2. **SEMrush** — Keyword research + rank tracking ($119/mo)
3. **Moz Keyword Explorer** — Keyword suggestions and difficulty ($99/mo)
4. **Serpstat** — All-in-one SEO platform ($69/mo)

### Step-by-Step Research Process

**Step 1: Brainstorm Seed Keywords (30 minutes)**
- Use the seed keyword list in this template
- Add Client-specific service terms
- List client questions from consultations
- Review competitor websites for terminology

**Step 2: Expand with Keyword Tools (2-3 hours)**

*Google Keyword Planner:*
1. Login to Google Ads → Tools → Keyword Planner → Discover new keywords
2. Enter 5-10 seed keywords at a time
3. Export results (CSV)
4. Filter by monthly search volume (>100 for EN, >500 for RU)
5. Note competition level (Low/Medium/High)

*AnswerThePublic:*
1. Enter main keyword (e.g., "SEO")
2. Collect question-based keywords (what, how, why)
3. Export visualization data
4. Organize by question type

*Google Search Console (if site exists):*
1. Go to Performance report
2. Export queries data (last 3 months)
3. Identify keywords you're already ranking for (position 1-100)
4. Find quick-win opportunities (position 11-20)

*Yandex Wordstat (Russian keywords):*
1. Go to wordstat.yandex.ru
2. Enter Russian seed keywords
3. Note search volume (monthly)
4. Check regional distribution
5. Export by clicking through pages

**Step 3: Competitor Analysis (2 hours)**
1. Identify 5-10 competing digital agencies
2. For each competitor, manually review:
   - Homepage: What keywords are they targeting?
   - Blog: What topics are they covering?
   - Top ranking pages: Search `site:competitor.com SEO` in Google
3. If using Ahrefs/SEMrush:
   - Enter competitor domain → Organic Keywords report
   - Filter: Position 1-10, Search volume >100
   - Export top 100 keywords
   - Identify gaps: Keywords they rank for that you don't

**Step 4: Analyze & Prioritize (1 hour)**

Create a spreadsheet with these columns:

| Keyword | Volume | Difficulty | CPC | Intent | Current Rank | Priority | Content Type | Target URL | Status |
|---------|--------|------------|-----|--------|--------------|----------|--------------|------------|--------|
| [keyword] | [monthly] | [0-100] | [$] | [T/C/I] | [rank] | [H/M/L] | [type] | [url] | [status] |

Sort by:
1. High volume + Low difficulty = Quick wins
2. High business relevance = Revenue potential
3. Search intent alignment = Conversion likelihood

## Next Steps After Keyword Research

### Phase 1: Setup (Week 1)
1. Complete keyword research spreadsheet with 100-200 keywords
2. Set up Google Search Console (if not already done)
3. Set up rank tracking (free: GSC or paid: Ahrefs/SEMrush)
4. Create content calendar spreadsheet

### Phase 2: Prioritization (Week 1)
1. Prioritize top 50 keywords for first 3 months
2. Map keywords to existing pages
3. Identify content gaps requiring new pages
4. Assign keywords to content types

### Phase 3: Content Planning (Week 2)
1. Create content briefs for top 10 priority articles
2. Plan internal linking structure (keyword clusters)
3. Set publication schedule (target: 2 articles/week)

### Phase 4: Execution (Month 1-3)
1. Begin content creation for high-priority keywords
2. Optimize existing pages with target keywords
3. Build internal links between related content
4. Monitor rankings weekly in Google Search Console

### Phase 5: Measure & Refine (Ongoing)
1. Track keyword rankings (weekly)
2. Monitor organic traffic
3. Analyze which content drives consultation requests
4. Refine keyword strategy based on performance
5. Identify new keyword opportunities monthly
