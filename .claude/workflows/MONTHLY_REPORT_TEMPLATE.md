## Инструкции по заполнению

### Перед созданием отчёта

1. **Запустить Content Audit** (последний день месяца):
   ```bash
   venv/bin/python scripts/content_audit/main.py --full --all
   ```

2. **Собрать данные** (для каждого сайта):
   - Объём контента: `research/content-audit/[domain-1]/site-content-audit-latest.csv` (EN)
   - Объём контента: `research/content-audit/[domain-2]/site-content-audit-latest.csv` (RU)
   - Топ страницы: `research/content-audit/[domain-1]/content-gaps-latest.md`
   - Ключевые слова: CSV колонка `top_keywords`
   - Метрики: CSV колонки `yandex_clicks`, `yandex_impressions`, `yandex_position`

### Заполнение секций

**Резюме:**
- Указать фактические цифры из CSV (кол-во статей, общий word_count)
- Рассчитать целевой трафик на основе keyword research

**Контент-план:**
- Заполнить таблицу из CSV (фильтр по датам публикации текущего месяца)
- Проверить word_count для каждой статьи

**Текущая эффективность:**
- Скопировать таблицу из `content-gaps-latest.md` → "Top 10 Performing Pages"
- Добавить выводы на основе данных (позиции, CTR, тренды)

**План на следующий месяц:**
- Проверить `content-gaps-latest.md` → "Content Gaps" для идей
- Использовать CSV `top_keywords` чтобы избежать дублирования тем

---

**Примечание:** Данные актуализируются автоматически при запуске Content Audit. Файлы `*-latest.*` всегда указывают на самый свежий отчёт.
